# Audition: Reusable Team Workflows with OpenAI Codex Skills (v1)

## Files
- `Audition Outline - Akmal Khan - Codex Skills v1.docx`: built from the blank Author Kit template
- `Audition Slides - Akmal Khan - Codex Skills v1.pptx` + `Audition Slides - preview.pdf`: 8 slides with diagrams, click builds, callouts and speaker notes
- `TIMED_NARRATION_SCRIPT.md`: 7:15 script with click, callout and switch cues
- `SLIDE_DECK_CONTENT.md`: per-slide visuals and build order
- `RECORDING_AND_DEMO_GUIDE.md`: how to record, the step-by-step demo in the Codex app, reset and editing checklist
- `CODEX_PROMPTS.txt`: the exact prompts
- `demo_reference_storyboard.mp4`: 2:36 silent reference built from real screenshots of the rehearsal, with callouts. **Not the audition recording.**
- `demo-code/`: a copy of the skill (`release-notes/`) and of the rehearsal output
- `verify_demo.py`: checks that the skill's script gives the expected result on the demo repo

The live demo projects are in the project root: `skills-take` (repo) and `skills-kit` (the skill to copy in).
