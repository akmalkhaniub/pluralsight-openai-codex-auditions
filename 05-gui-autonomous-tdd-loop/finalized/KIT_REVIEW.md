## Changes to the old outline and TDD material

The supplied Akmal Khan outline and Guardrails deck describe AGENTS.md and approval policies, not TDD.
Their promises that every action is approved and every run obeys project rules are too strong. They also script a specific agent mistake. The finalized TDD lesson omits those claims.
The old outline says 3 books at $20 with 25% off should total $45, while one slide calls a $15 charge an overcharge. It would be an undercharge. That scenario is not used in the final lesson.
The old TDD material omits the refactor phase, calls four tests exhaustive, and equates file context with read-only protection.
The final lesson includes eight focused examples, Decimal rounding, a real refactor decision and repeated verification. Tests are an executable sample of the contract, not a correctness guarantee.
Use the actual installed extension's context and review controls. Do not promise hash chips, automatic split diffs or Accept All buttons.
