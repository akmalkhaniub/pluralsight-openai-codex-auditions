# Topic 1: Rapid Codebase Onboarding Using OpenAI Codex

## Package Contents
* `AUDITION_OUTLINE.md`: The official filled-out Pluralsight Video Audition Outline form.
* `SLIDE_DECK_CONTENT.md`: Slide-by-slide layout matching the Pluralsight PowerPoint template with on-click animation cues.
* `TIMED_NARRATION_SCRIPT.md`: Word-for-word spoken transcript with second-by-second timestamps and visual callout instructions.
* `demo-code/`: The target multi-tier microservice repository used during the 3-minute demo screencast.

## How to Record Your Audition
1. **Prepare Slides:** Copy the slides from `SLIDE_DECK_CONTENT.md` into the official Pluralsight Audition PowerPoint template. Set bullet animations to *Appear* or *Fade* on click.
2. **Setup VS Code:**
   * Open the `demo-code/` folder in VS Code.
   * Hide the status bar, activity bar, and terminal clutter (`Ctrl+B` to toggle sidebar).
   * Increase editor font to 16–18pt (or set zoom to 125%).
3. **Practice with the Script:**
   * Follow `TIMED_NARRATION_SCRIPT.md`. Maintain natural inflection and observe intentional 1-second pauses when switching slides.
   * In the screencast, **do not wave the mouse cursor**. In post-production, draw orange/blue bounding boxes around files and code snippets.
4. **Target Time:** 7 minutes 15 seconds (well within Pluralsight's 5–8 minute rubric).
